# 💉 H1N1 Vaccine Prediction using Logistic Regression

## 📌 Project Overview

This project focuses on predicting whether a person received the **H1N1 vaccine** using demographic, behavioral, health, and perception-related features.

The project uses **Exploratory Data Analysis (EDA)** and **Logistic Regression** to analyze the factors associated with H1N1 vaccination and build a binary classification model.

The dataset contains **26,707 records and 34 columns**. The target variable is `h1n1_vaccine`. 

---

## 🎯 Objectives

- Understand the H1N1 vaccination dataset
- Perform Exploratory Data Analysis
- Analyze vaccination-related factors
- Identify and handle missing values
- Prepare data for machine learning
- Build a Logistic Regression classification model
- Evaluate classification performance
- Analyze the confusion matrix and classification metrics
- Calculate ROC-AUC score

---

## 📊 Dataset

The dataset contains information related to:

- H1N1 awareness
- H1N1 worry
- Vaccination recommendations
- Preventive behavior
- Health conditions
- Demographics
- Employment
- Income
- Education
- Housing
- Household information
- H1N1 vaccination status
